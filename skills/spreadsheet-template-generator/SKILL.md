# spreadsheet-template-generator

Generate a template spreadsheet based on a provided purpose.

## Intent

This skill creates reusable spreadsheet templates for various purposes, such as:
- Project tracking 
- Meeting notes
- Data collection forms
- Budget planning
- Task management
- Research documentation

The generated templates are designed to be flexible and can be adapted to specific use cases while providing a solid foundation.

## Input Contract

### Interactive Mode
- Start with "generate spreadsheet template", "create template", or "make spreadsheet template"
- Prompt user for the purpose of the spreadsheet
- Ask how many columns/rows they'd like to include as a starting point

### Single-command Mode
- `generate spreadsheet template — Purpose: <description of what you want>; Columns: <number>`

## Behavior

### Execution Steps
1. **Accept Input** - Get the purpose of the spreadsheet from user input
2. **Analyze Purpose** - Determine appropriate columns based on use case
3. **Generate Template** - Create a structured CSV-like template with appropriate headers and sample data
4. **Output Format** - Provide a text-based format that can be easily converted to a real spreadsheet

### Supported Use Cases
- Project tracking
- Meeting notes
- Data collection forms
- Budget planning
- Task management
- Research documentation

## Template Structure

Templates generated by this skill will include:
1. Appropriate column headers based on the purpose
2. Sample data points to illustrate format expectations
3. Clear descriptions and instructions for each field
4. Format guidance for common use cases

## Implementation Notes

This skill generates a text-based representation of spreadsheet templates which can then be easily converted to actual spreadsheets using standard tools.

## Guardrails

### Never Fabricate Rules
- **Purpose Focus** - Only generate templates based on explicitly provided purposes
- **No Data Generation** - Do not generate real data, only structure and headers

### Idempotent Rules
- Generating the same template twice should produce identical output
- Templates are deterministic based on input purpose
