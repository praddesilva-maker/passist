# Skills

This is the canonical list of skills in the passist repository.

| Skill Name      | Description                                             |
|-----------------|---------------------------------------------------------|
| skill-reviewer   | Review one skill to deliver an expert critique for distribution-readiness |
| skill-hygiene-check | Audit fleet for conformance and return PASS/FAIL/N-A table |
| use-capability   | Route user's stated goal to the right existing tool or skill and run it |
| excel-creator    | Create comprehensive Excel spreadsheets with multiple sheets, formulas, and formatting |

## Quality Gate Skills

These skills work together to maintain quality in the skill fleet:

1. **skill-reviewer** - Subjective expert critique assessing quality against framework conventions 
2. **skill-hygiene-check** - Mechanical conformance sweep verifying documentation policy compliance
