Home Budget Tracker - Complete Setup Instructions

============================================

This document provides detailed instructions for setting up your home budget tracker Excel spreadsheet based on the template described in budget_spreadsheet_instructions.md.

INSTRUCTIONS FOR CREATING THE EXCEL SPREADSHEET:

1. OPEN EXCEL:
   - Launch Microsoft Excel or Excel-compatible software (Google Sheets, LibreOffice Calc)

2. CREATE THE 5 SHEETS:
   - Sheet 1: "Expense Tracking"
   - Sheet 2: "Expense Categories"  
   - Sheet 3: "Savings Goals"
   - Sheet 4: "Monthly Summary"
   - Sheet 5: "Budget Tracking"

3. SET UP EACH SHEET:

Sheet 1: Expense Tracking
=========================
Columns (A to H):
A1: Date
B1: Category  
C1: Description
D1: Amount ($)
E1: Payment Method
F1: Budgeted Amount ($)
G1: Actual vs Budget
H1: Notes

Sample rows:
A2: 1/1/2023
B2: Housing  
C2: Rent
D2: 1200.00
E2: Check
F2: 1200.00
G2: =F2-D2
H2: Monthly rent payment

Sheet 2: Expense Categories
=========================
List of standard budget categories:
- Housing
- Food
- Transportation
- Utilities
- Entertainment
- Healthcare
- Education
- Clothing
- Insurance
- Other

Sheet 3: Savings Goals  
=====================
Columns (A to I):
A1: Goal Name
B1: Target Amount ($)
C1: Current Savings ($)
D1: Progress (%)
E1: Timeline (Months)
F1: Monthly Contribution ($)
G1: Start Date
H1: Status
I1: Notes

Sample rows:
A2: Emergency Fund
B2: 5000.00  
C2: 2500.00
D2: =(C2/B2)*100
E2: 12
F2: =(B2-C2)/E2
G2: 1/1/2023
H2: In Progress
I2: 3 months left to reach goal

Sheet 4: Monthly Summary
========================
Columns (A to H):
A1: Month/Year
B1: Total Income ($)
C1: Total Expenses ($)
D1: Net Savings ($)
E1: Budget Variance ($)
F1: Categories Overview
G1: Goal Progress Summary
H1: Notes

Sheet 5: Budget Tracking
=======================
Columns (A to G):
A1: Category
B1: Monthly Budget ($)
C1: Actual Spending ($)
D1: Difference ($)
E1: Percentage of Budget Used (%)
F1: Status
G1: Notes

FORMULAS TO USE:
- Actual vs Budget (Expense Tracking sheet): =F2-D2
- Progress (%): =(Current Savings / Target Amount) * 100
- Monthly Contribution: =(Target Amount - Current Savings) / Timeline (months)  
- Percentage of Budget Used (Budget Tracking): =C2/B2*100

DATA VALIDATION:
- Category column (Expense Tracking sheet): Set up data validation with list from Expense Categories sheet
- Payment Method column (Expense Tracking sheet): Check, Credit Card, Debit Card, Cash
- Status column in Savings Goals: Not Started, In Progress, Completed
- Status column in Budget Tracking: Over, Under, Budgeted

CHARTS AND VISUALIZATIONS:
1. Bar chart showing monthly expenses by category (from Expense Tracking)
2. Pie chart showing expense distribution percentages (from Budget Tracking)  
3. Line chart for savings progress against goals (from Savings Goals)
4. Progress bars for each savings goal using conditional formatting
