# Home Budget Spreadsheet Summary

## Overview
This Excel spreadsheet provides a comprehensive home budget tracking solution with 5 distinct sheets designed to help manage personal finances effectively.

## Structure
The budget tracker consists of the following 5 sheets:

### 1. Expense Tracking Sheet
- **Purpose**: Record all daily expenses
- **Columns**:
  - Date (mm/dd/yyyy)
  - Category (Housing, Food, Transportation, etc.)
  - Description
  - Amount ($)
  - Payment Method (Cash, Credit Card, Debit Card, Check)
  - Budgeted Amount ($) - Monthly budget for each category
  - Actual vs Budget - Difference between budgeted and actual amounts
  - Notes

### 2. Expense Categories Sheet
- **Purpose**: List all expense categories available for tracking 
- **Categories**:
  - Housing
  - Food
  - Transportation
  - Utilities
  - Entertainment
  - Healthcare
  - Education
  - Clothing
  - Insurance
  - Other

### 3. Savings Goals Sheet
- **Purpose**: Track and monitor savings progress toward specific goals
- **Columns**:
  - Goal Name (Emergency Fund, Retirement, etc.)
  - Target Amount ($)
  - Current Savings ($)
  - Progress (%) - Percentage of goal reached
  - Timeline (Months) 
  - Monthly Contribution ($) - Amount needed to save each month to reach goal
  - Start Date
  - Status (Not Started, In Progress, Completed)
  - Notes

### 4. Monthly Summary Sheet
- **Purpose**: Provide a monthly overview of financial activity
- **Columns**:
  - Month/Year
  - Total Income ($)
  - Total Expenses ($)
  - Net Savings ($) - Income minus expenses
  - Budget Variance ($) - Difference between budgeted and actual expenses
  - Categories Overview - Text notes on spending by category
  - Goal Progress Summary - Text notes about savings goal progress
  - Notes

### 5. Budget Tracking Sheet
- **Purpose**: Monitor how categories compare to their budgets
- **Columns**:
  - Category
  - Monthly Budget ($)
  - Actual Spending ($) 
  - Difference ($) - Over/under budgeted amount
  - Percentage of Budget Used (%) 
  - Status (Over, Under, Budgeted) - Text indicator
  - Notes

## Key Features
- Pre-populated with sample data to demonstrate functionality
- Formatted headers with blue background for easy identification
- Auto-adjusted column widths for better readability
- Designed for easy tracking and analysis of financial habits

## How to Use
1. Open the Excel file in Microsoft Excel or compatible software
2. Add new expense records to the Expense Tracking sheet
3. Update savings goals as you make progress toward them
4. Use filters to analyze spending patterns by date or category
5. Refer to the Monthly Summary for a holistic view of your finances

## Benefits
- Helps users stay within budget limits
- Tracks financial progress toward specific goals
- Provides insights into spending patterns and trends
- Encourages financial discipline through regular monitoring
